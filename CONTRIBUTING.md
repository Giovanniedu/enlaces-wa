# Cómo contribuir
1. Haz fork y crea una rama: `git checkout -b mi-mejora`
2. Sin dependencias nuevas: el proyecto usa solo la biblioteca estándar de Python.
3. Agrega/actualiza pruebas en `tests/` y verifica: `python -m unittest discover -s tests -v`
4. Abre un Pull Request describiendo el problema que resuelves (no solo el cambio).
